# Créditos

## Projeto original

**Dragon Evolution** (DBE) — add-on de Dragon Ball para Minecraft Bedrock.

- Autor: **About04**
- Versão de origem identificada: `pack.credits = DBE v1.5.0 by About04`; manifests na versão `1.6.17`.
- O Dragon Universe é construído sobre essa base. Toda a estrutura original (núcleo de scripts, modelos, texturas, animações, sons, entidades, itens e dados) é trabalho de About04, salvo onde indicado o contrário.
