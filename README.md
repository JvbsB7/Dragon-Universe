# 🏗️ Dragon Universe — Estruturas

Repositório dedicado às construções e estruturas desenvolvidas para o projeto **Dragon Universe**, inspirado no universo de Dragon Ball para Minecraft Bedrock Edition.

## 📂 Estruturas disponíveis

### 🏆 Torneio do Poder

Pasta destinada às construções relacionadas ao Torneio do Poder, incluindo arenas e outras estruturas que poderão ser utilizadas no projeto.

## 🎯 Objetivo

- Organizar as estruturas do projeto separadamente dos arquivos da addon.
- Armazenar construções para testes e futuras implementações.
- Facilitar a manutenção, atualização e compartilhamento das estruturas.
- Preparar os arquivos para possível integração com a addon Dragon Universe.

## 🌿 Branch

Esta branch é dedicada exclusivamente ao desenvolvimento e armazenamento de estruturas.

- `main`: arquivos principais da addon Dragon Universe.
- `Estruturas-teste`: construções e estruturas em desenvolvimento.

## 🛠️ Projeto

**Dragon Universe** — Projeto de Minecraft Bedrock Edition inspirado em Dragon Ball.
