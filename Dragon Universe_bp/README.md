# Português:
Dragon Universe é um add-on de Dragon Ball para Minecraft Bedrock, desenvolvido pela Equipe Dragon Universe. Dragon Ball é uma marca registrada de seus criadores, e este projeto não tem nenhuma ligação oficial com eles. Feito por fãs, para fãs.
Equipe Dragon Universe
Cabelos de Goku, Vegeta, Gohan, Trunks e Broly: modelos e texturas do DragonMineZ 2.2.1, de Yuseix300 e ezShokkoh, licença GPL-3.0, convertidos para Bedrock pela equipe Dragon Universe.
